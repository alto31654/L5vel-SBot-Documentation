# L5vel-SBot-Documentation
This is my documentation of the work I have done on the SBots, including assembly guides, costs, set up guides, and 3D models

SUMMER SUMMARY:
For this summer semester, I had began new configurations for the SBOT's, including 1 arm with lift, dual arm, and 3 arm configurations. I have also retrofitted the first Sbot to have a lift.
I created an alternate version of the 3 arm base that is ready for assembly. I have also been working on improving the SetUp.md file within the SBot files to cover any missing steps
or to add in steps to do when certain issues arise. I have created assembly guides on how to build the robots from the ground up and how to configure the components within it.
I have also been developing the physical aspects of two bumper systems - one that is just a 3D printable cushion that goes on the corners of the robot, and one that detects when an impact occurs to actiate the E-Stop in the driving motors.
In my spare time, I am developing a shroud for the XArm 850s that will contain the wires for the external cameras and researching how to route the camera data through the arm itself to remove the reason for the shrouds in the first place.
I have also briefly worked with learning how to write code for a sensor I was trying to implement for the bumper; however, we ended up using a different sensor that doesn't need as much code.
